# Trekking Management Application

A web application for managing trekking activities. The system supports three types of users, each with different roles and permissions.

## User Roles

- **Admin:** Has the highest level of access and manages the overall trekking system, including users, staff, and trekking operations.
- **Trek Staff:** Manages and coordinates assigned treks, updates trek details, and assists participants.
- **User (Trekker):** Registers, books treks, and participates in trekking activities.
